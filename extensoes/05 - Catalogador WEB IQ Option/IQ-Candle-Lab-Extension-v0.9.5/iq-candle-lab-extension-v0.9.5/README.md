# IQ Candle Lab — v0.9.5

## Remoção completa dos tooltips flutuantes

Os quadros de probabilidades que apareciam sobre os cards foram removidos de todos os pontos da extensão.

Motivo:

- podiam permanecer presos na tela;
- bloqueavam informações;
- apareciam em vários cards ao mesmo tempo;
- prejudicavam a navegação.

## Onde as probabilidades continuam disponíveis

### Página de análise

Clique em uma estratégia para abrir o popup detalhado. As probabilidades aparecem em um bloco fixo dentro do popup.

### Janela flutuante

Clique em uma estratégia para abrir o modo focado. As probabilidades aparecem em um bloco fixo dentro do card expandido.

## Informações preservadas

- IN
- Até G1
- Até G2
- LOSS
- Recuperação no G1
- Recuperação no G2
- Dependência de Gale
- Amostra

Não existe mais nenhum tooltip/ALT flutuante relacionado às probabilidades.
